# Contributing

Current project is under active development.

---

# Coding Style

- C99
- 4-space indentation
- Opening brace on next line
- Descriptive function names
- One responsibility per function

---

# Commits

Keep commits small.

One logical change per commit.

Examples:

- Implement PMM
- Add PMM tests
- Refactor heap allocator

Avoid mixing unrelated changes.

---

# Testing

Every new subsystem must include tests.

No feature is considered complete until it has:

- unit tests
- stress tests

---

# Philosophy

Correctness first.

Optimization second.

Every optimization must preserve behavior.
